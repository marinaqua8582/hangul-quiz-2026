# 등급 캐릭터 이미지 안내

이 폴더에 다음 5개 이미지 파일을 업로드하시면 결과 화면에 자동으로 표시됩니다.

1. `king.png` - 한글 대왕 (95~100점)
2. `jangwon.png` - 한글 장원 (85~90점)
3. `general.png` - 한글 장군 (70~80점)
4. `scholar.png` - 한글 선비 (50~65점)
5. `student.png` - 한글 학동 (0~45점)

* 권장 해상도: 512x512 이상 (1:1 비율 투명 PNG 또는 한지 배경)
* 이미지가 아직 업로드되지 않았더라도 웹앱의 fallback UI(전통 어새 및 관인 문양)가 작동하여 화면이 깨지지 않고 정상 표시됩니다.
